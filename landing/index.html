获取

三个平台，下载即用

Windows GoStudy.exe 双击即用，用 Edge / Chrome 的应用窗口打开界面。 Android GoStudy-android-release.apk Android 8.0+，自签名可直接安装，约 65 MB。 Linux GoStudy-linux-amd64 / arm64 静态单文件，chmod +x 后直接运行。

从源码运行

git clone https://github.com/xianshujun/awsome-go-study
cd awsome-go-study/app
go run ./cmd/gostudy -no-browser

需要 Go 1.25+ 与 Node.js 22.12+（首次构建前端）。构建 Windows、Android 与 Linux 产物的完整命令见 应用说明。
