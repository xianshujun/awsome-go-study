# 培训：Go 程序的引导式实践

以下机构提供 Go 语言相关的培训课程与咨询服务，整理自 go.dev/learn 页面的「Training」一节。

> **说明**：本页为翻译整理，课程大纲、排期、价格等以各机构官网为准。授课语言与地区请直接咨询相应机构。
