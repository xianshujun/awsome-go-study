# 图书

以下是 go.dev/learn 页面推荐的 Go 语言书籍。

> **说明**：书籍正文均受版权保护，无法在本项目中翻译收录。本页仅整理书目信息，并附上官方页面 / 购买链接，供读者自行查阅。

---

<a id="gopl"></a>
## 《Go 程序设计语言》（The Go Programming Language）

- **作者**：Alan A. A. Donovan、Brian W. Kernighan
- **简介**：常被社区称为「Go 圣经」，由 Go 核心团队成员参与撰写，系统讲解语法、接口、并发、测试与工程实践，是进阶 Go 的经典教材。
- **官方链接**：<https://www.gopl.io/>

---

<a id="get-programming-with-go"></a>
## 《Get Programming with Go》

- **作者**：Nathan Youngman、Roger Peppé
- **简介**：面向初学者的入门书，用一系列短小章节循序渐进地介绍 Go 基础，适合零基础或从其他语言转来的读者。
- **官方链接**：<https://www.manning.com/books/get-programming-with-go>

---

<a id="go-blueprints"></a>
## 《Go 程序设计蓝图》（Go Programming Blueprints）

- **作者**：Mat Ryer
- **简介**：通过一个个真实项目贯穿讲解 Go 的实际应用。该项目仓库是本书的官方源代码仓库。
- **官方源码仓库**：<https://github.com/matryer/goblueprints>

---

<a id="introducing-go"></a>
## 《Go 语言入门》（Introducing Go）

- **作者**：Caleb Doxsey
- **简介**：篇幅精简的入门读物，快速覆盖 Go 的基本语法、类型、函数、并发与包等核心概念。
- **官方链接**：<https://www.oreilly.com/library/view/introducing-go/9781491941997/>

---

<a id="concurrency-in-go"></a>
## 《Go 中的并发》（Concurrency in Go）

- **作者**：Katherine Cox-Buday
- **简介**：深入讲解 Go 并发模型的专著，涵盖 goroutine、channel、并发模式、context 与并发安全等主题。
- **官方链接**：<https://www.oreilly.com/library/view/concurrency-in-go/9781491941294/>
